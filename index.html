01

What moves, and why

Every motion is tied to something the app is doing. At rest the theme is nearly still, so a long read stays calm. Reduced motion freezes everything: ON TIME at rest, BOARDING while a turn runs.

TriggerWhat you seeWhy
At restThe board reads ON TIME. A station clock's hand ticks every few seconds beside it, and now and then one destination row flips to a new city.Calm ambient life you barely notice.
Turn startsThe gutter board rattles hard for a few seconds, rows settling one after another, and the status row flips to BOARDING. Then it holds, refreshing one row now and then. The departure lamp lights.The busiest thing on screen says the agent is busy.
Turn runningAmber runway lights run along the header and the composer edge. The Working row is a flap tile cycling letters into BOARDING.Peripheral cues that need no reading.
Background threadThe busy thread row gets its own slow chase line.Spot other agents at a glance.
Turn completeThe board clatters back to ON TIME, the lamp flashes and the header rule fades from amber, once, only when a turn actually ends.A clear finish line.
Hover and focusA platform rail lights beside the hovered thread; the composer edge turns amber on focus.Direct, quiet feedback.
Narrow windowThe board shrinks to fit the gutter (about 140px wide at 1440px). Below that it hands over to a one-row ON TIME / BOARDING tile in the right gutter, which rattles and re-announces like the full board. Nothing sits behind thread names.The state signal survives at 1280px.

Install

1

Copy the theme

One JSON file, no extra assets.

Download
2

Paste it in T3 Code

Open Settings › Appearance › Add theme, paste, and save. Pick Departures from the theme list.

3

Or use the CLI

Fetch the file and apply it.

curl -fsSL -o departures.json https://joshsaintjacque.github.io/t3code-theme-departures/departures.json
~/.t3/bin/t3 theme set departures.json
